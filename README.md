# 山河纪 · 御极

一款以干支纪年、四时朝议为骨架的文字向帝王治国模拟游戏。

## 玩法

- 御定两字年号，择辅臣、授官职，亦可不设辅臣。辅臣之位有二，各领一职；辅臣怀有特殊能力，岁末依官职考成增益国势，也会在相应朝议中进言献上更优之策。
- 每岁四时，每时一事，但每年只有三点行动：亲理一桩耗一点，搁置不耗，点尽之后余季只可搁置。日辰随机带吉、凶、平，日常事件每次从五条线索中随机呈现二至四项，并至少保留一条激进、一条保守的选择。
- 抉择前不列利害，择定后方于本季总变中结算；日常朝政另有顺逆之数，六成顺遂、四成波折。每条选择带政绩权重（-2、0、+1、+3），岁末合当年所积政绩而计：满六为顺，三至五为平，不足三为厄；当年尽数搁置，岁评为「庸」。
- 事件文本、朝议对象与「殿上侧闻」会随季节、国势、辅臣和官职变化。日常事件池含七十余个模板与若干季节/情境变体；一朝之内优先抽取本朝尚未演过的事，事池尽竭后亦避开最近十余事，方才重演。
- 权臣、府库、民变、军势四值此消彼长，任一越界即触发对应终局；庸年逾在位之半，亦会另开「庸政」终卷。
- 一朝另有仅此一遇的「异闻」：方士献丹、山中隐士、诸侯请封、群臣请封禅、城下之盟。某些抉择会直接落定国祚。
- 岁末另有史评，终局依谥法定谥，并作太史公总评。
- 结局可另开新朝；唯得善谥方可继承四值、传于下一世（平谥与恶谥皆须重开）。承继时新君初立，府库、军势各减十，民变、权臣各增十，四值再止于边界之内。
- 顺利承继时，新朝首季必先办「先皇葬仪」：此礼一朝仅此一遇，不系日辰，亦不入岁评；若搁置不办，权臣与民变各增二。此后前朝积弊未除，部分日常朝政的有害效用会随世次加重，用以模拟王朝衰落。
- 顺利承继时，前朝首席辅臣可留任新朝，仍领旧职，其岁末考成较寻常辅臣更著。新旧两代辅臣同朝后，会有一回「朝局」之事：或联章共奏，或互上弹章（三策中随机呈现两策），一朝仅此一见。
- 已亲历的国祚结局会以其所得谥号为记收入「结局图鉴」；未亲历者书为「未启」。存档、本纪与图鉴均留在本地浏览器。

## 内容结构

- `src/game/engine.ts`：朝议推进、岁评、国势结算与终局判定。
- `src/game/events.ts`：日常事件池入口，合并基础事件与扩充事件，并挂载变体。
- `src/game/events-extra.ts`、`src/game/events-more.ts`：扩充的日常事件模板。
- `src/game/event-scenes.ts`：日常事件后的场景余笔，为每条基础事件补一段白描。
- `src/game/event-variants.ts`：按季节与情境替换的叙事变体。
- `src/game/chains.ts`：改编自史事的事件链；`src/game/special-events.ts`：仅此一遇的异闻。
- `src/game/content.ts`：谥法、结局文案与图鉴次序；`src/game/storage.ts`：本地存档、本纪与图鉴迁移。

旧版本存档中的 `merit` 会在读取时自动折算为 `weight`；旧的单辅臣存档会迁为双辅臣结构，缺失的侧闻、政绩、岁评与朝局字段会补为安全默认值。

## 开发

```sh
npm install
npm run dev
```

类型检查与生产构建：

```sh
npm run type-check
npm run build
```

构建产物位于 `dist/`，可直接部署为静态站点。
